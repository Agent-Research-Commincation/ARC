# 공유용 실험 결과

[결과 묶음 ZIP](agent-communication-v3-1-20260912-reader.zip)과 [SHA-256 체크섬](agent-communication-v3-1-20260912-reader.zip.sha256)을 함께 전달한다. 이 ZIP에는 최신 독자용 보고서와 원본·평가·분석이 들어 있다. 보고서는 방식별 효율성 가설 → 공통 회의 문제와 단계별 과정 → 실험 결과 → 핵심 인사이트 순서로 구성했다.

현재 자료는 2026년 9월 11일의 여섯 방식 × 5회, 총 30회다. 성공 29회·최적 28회이며 실제 모델을 추가 실행하지 않았다.

ZIP 크기는 약 9.3 MB다. [묶음 검증 결과](agent-communication-v3-1-20260912-reader.verification.json)와 [다른 위치에 압축을 풀어 수행한 검증](agent-communication-v3-1-20260912-reader.relocation.json)을 확인할 수 있다. 30회 평가·주요 수치 재현, 독자용 링크 927개, 묶음 파일 1,532개의 체크섬이 통과했다. 오프라인 테스트 119개도 통과했다.

[이전 배포본](agent-communication-v3-1-20260912.zip)과 [기존 체크섬](agent-communication-v3-1-20260912.zip.sha256)은 그대로 보존한다. 새 묶음은 설명 문서를 재구성한 배포본이며, 새로운 실험이나 평가 정책 변경을 의미하지 않는다.

## 읽고 검산하기

1. ZIP과 체크섬 파일을 같은 폴더에 놓는다. macOS/Linux에서는 `shasum -a 256 -c agent-communication-v3-1-20260912-reader.zip.sha256`으로 전달 파일의 일치를 확인할 수 있다.
2. 원하는 위치에 압축을 풀고 안쪽 `README.md`에서 결과·비교표·실제 대화를 읽는다. 표시용 링크는 상대 경로다.
3. Python 3.9 이상에서 아래 명령으로 재현한다. Codex 로그인이나 네트워크는 필요하지 않다.

```sh
python3 scripts/verify_release.py --bundle . --output ../new-replay
```

명령은 압축을 푼 묶음의 README가 있는 폴더에서 실행한다. `../new-replay`는 아직 존재하지 않는 새 출력 폴더여야 한다. 묶음 자체는 변경하지 않는다.

30회 관찰표를 선택한 평가 코드와 기존 주석으로 다시 계산하고, 비교표·요청별 비용·사례 근거를 기존 수치와 대조한다. 체크섬·평가·집계가 다르면 실패한다. 결과는 출력 폴더의 `verification.json`과 `analysis/`에 남는다.

- 실행 조건·문제·실행 계획, 봉인된 30회 원본과 당시 소스.
- 선택한 사후 평가의 코드·manifest·정책 버전·AI 주석·원문 근거와 판정.
- 사람이 읽는 대화·Agent별 기록·비교표·인사이트.
- 독립적으로 다시 계산하는 분석 코드와 평가 재생 코드, 파일별 체크섬.
- 자연어의 명시 오류 6건, 확인된 네 누락, 모호한 표현 1건을 구분하는 설명과 해석 민감도.

자연어 판정 재현은 사람의 독립 검수나 정보 완전성의 검증과 다르다. 실행기 요청/턴 225회와 사용량 갱신 229개도 구분하며 제공자 내부 호출 수는 측정하지 않았다. 총비용은 미측정이고 모델 비용은 고정 API 단가에 따른 추정이다.

원본의 과거 절대 경로는 출처 정보로 남아 있지만 재현 명령의 입력 경로로 사용하지 않는다. Python 감사 훅으로 평가·분석 중 묶음·출력·표준 라이브러리 밖의 파일 읽기와 네트워크·프로세스 실행을 차단한다. 운영체제 격리나 제공자 측 독립 감사를 의미하지 않는다.
