# 기본 상태 협업 · 동일 조건 5회 결과

2026-09-09, 슬롯 번호표를 명시한 동일 조건에서 기본 상태 협업을 매회 새 A·B 세션으로 5회 실행했다. 이 문서는 해당 다섯 회차의 결과를 집계한다.

## 고정 조건과 실행 확인

- 다섯 회 모두 같은 합성 일정, `gpt-5.6-luna`, 추론 수준 `high`를 사용했다.
- 각 회차마다 A·B를 새 세션으로 생성했다. 실제 세션 ID 10개가 모두 서로 다름을 확인했다.
- 각 Agent는 자기 팀 3명의 일정만 입력받았다. 기획 대화, 이전 결과나 평가기 정답을 제공하지 않았다.
- 메시지 형식을 지정하지 않고 내용과 전략을 Agent가 선택했다. A부터 교대, 도구 제한, JSON 입력·행동 외피, 동일한 최종 제출 규칙은 공통으로 유지했다.
- 모든 회차에 동일한 0~11 슬롯 번호표를 제공했다. 실행 전후 설정·문제·소스 해시 일치를 확인했다.
- 5회가 끝날 때까지 설정을 바꾸지 않았으며 성공을 채우기 위한 추가 실행도 없었다.

여기서 기본 상태는 이 실험 환경에서 소통 형식을 지정하지 않은 상태다. Codex 제품의 모든 기본 기능을 켠 상태나 통상적인 Agent 전체를 대표하는 기준은 아니다.

## 관찰한 협업 방식

다섯 회 모두 A가 B팀의 일정·선호 전체를 먼저 요청하고, B가 정보를 보내면 A가 시간표를 제안하고 B가 수락했다. 자연어와 배열·집합·숫자 표기를 섞어 사용했다. 순수 자연어만 쓰도록 제한한 1단계와는 조건이 다르다.

2·5회차에서는 B도 A팀 원자료를 요청했고, A는 원자료와 후보 시간표를 함께 보냈다. 2·3회차에서는 수락 이후 확인 메시지가 한 번 더 오갔다. 3·4회차에서 A는 동점 최적해를 함께 언급했고, 4회차에서는 가능한 슬롯별 점수도 공유했다. 최종 선택은 다섯 회 모두 같았다.

이는 이 문제에서 관찰된 메시지와 행동의 패턴이다. 공개되지 않은 내부 추론이나 실제 탐색 알고리즘을 단정하지 않는다. 같은 문제 5회의 성공을 다른 과제의 성공률로 일반화하거나, 슬롯 번호표 보완의 인과 효과를 확정하지 않는다.
