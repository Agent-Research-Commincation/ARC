# 문서 안내

이 프로젝트는 두 Agent가 서로 다른 정보를 가지고 하나의 회의 일정을 정할 때, 여섯 소통 방식의 행동과 효율을 비교한다. **방식별 30회·총 180회의 본실험을 계획하며 현재 결과는 없다.**

## 읽는 순서

| 문서 | 답하는 질문 |
|---|---|
| [실험 계획](experiment-plan.md) | 각 방식에 어떤 가설을 세우고, 어떤 과정을 관찰하며, 결과에서 무엇을 판단하는가? |
| [실험 조건](phase-1-experiment.md) | 같은 문제·모델·30회 배정을 어떻게 유지하는가? |
| [지표와 검수 기준](metrics.md) | 결과 품질·비용·시간·전송량과 대화 오류를 어떻게 확인하는가? |
| [실행 방법](experiment-operation.md) | 원하는 단계를 실행하고 실제 대화를 저장·검수하려면 무엇을 하는가? |

[실험 계획](experiment-plan.md)은 프로젝트 가설, 공통 문제와 방식별 과정, 결과, 인사이트 순서다. 결과와 인사이트는 미실행 상태를 명시하고 실제 기록이 생성된 뒤 작성한다. 예상 과정이나 가설을 실제 Agent의 발화·관측 결과로 소개하지 않는다.

실행 요청의 1~6단계는 소통 방식 번호다. [프로젝트 README의 1~4차 연구](../README.md)는 후속 확장까지 포함한 연구 범위다.
