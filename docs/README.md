# 문서 안내

이 프로젝트는 두 Agent가 서로 다른 정보를 가지고 하나의 회의 일정을 정할 때, 여섯 소통 방식의 행동과 효율을 비교한다. **1차 본실험은 방식별 30회·총 180회 실행을 완료했다.** 결과와 해석은 [실험 보고서](experiment-report.md), 회차별 근거는 [실제 대화 기록](../result/20260912T170838Z-plan-22772406666b/README.md)에서 확인한다.

## 읽는 순서

| 문서 | 답하는 질문 |
|---|---|
| [실험 보고서](experiment-report.md) | 실제 180회에서 어떤 결과와 대화 행동이 관찰됐고, 어디까지 해석할 수 있는가? |
| [실제 대화 기록](../result/20260912T170838Z-plan-22772406666b/README.md) | 각 회차에서 무엇을 공유·제안·수정·제출했으며 어떤 근거로 판정했는가? |
| [실험 계획](experiment-plan.md) | 각 방식에 어떤 가설을 세우고, 어떤 과정을 관찰하며, 결과에서 무엇을 판단하는가? |
| [실험 조건](phase-1-experiment.md) | 같은 문제·모델·30회 배정을 어떻게 유지하는가? |
| [지표와 검수 기준](metrics.md) | 결과 품질·비용·시간·전송량과 대화 오류를 어떻게 확인하는가? |
| [실행 방법](experiment-operation.md) | 원하는 단계를 실행하고 실제 대화를 저장·검수하려면 무엇을 하는가? |

[실험 계획](experiment-plan.md)은 실행 전에 정한 가설, 공통 문제와 방식별 과정, 결과 보고와 인사이트 도출 기준을 보존한다. 실제 관측값과 사례는 [실험 보고서](experiment-report.md)로 구분해 연결한다. 가설을 실제 Agent의 발화나 관측 결과로 소개하지 않는다.

## 방식별 대화 찾기

각 방식의 안내에서 30회차의 대화, Agent별 기록, 선택한 검수 근거를 찾을 수 있다.

| 단계 | 읽기용 기록 |
|---|---|
| 1 · 자연어 | [30회 대화](../result/20260912T170838Z-plan-22772406666b/stage-01-natural-language/README.md) |
| 2 · JSON | [30회 대화](../result/20260912T170838Z-plan-22772406666b/stage-02-json/README.md) |
| 3 · 논리식·관계 표현 | [30회 대화](../result/20260912T170838Z-plan-22772406666b/stage-03-relations/README.md) |
| 4 · 고정 의미 특성 벡터 | [30회 대화](../result/20260912T170838Z-plan-22772406666b/stage-04-fixed-vector/README.md) |
| 5 · 바이트코드 | [30회 대화](../result/20260912T170838Z-plan-22772406666b/stage-05-bytecode/README.md) |
| 6 · 공동 기호 언어 | [30회 대화](../result/20260912T170838Z-plan-22772406666b/stage-06-shared-dictionary/README.md) |

실행 요청의 1~6단계는 소통 방식 번호다. [프로젝트 README의 1~4차 연구](../README.md)는 후속 확장까지 포함한 연구 범위다. 1차의 실행을 완료했으며 사람의 기록 이해도, 다른 문제군, 요소별 효과 분리를 다루는 2~4차는 후속 계획으로 유지한다.
