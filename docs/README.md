# Agent 소통 방식 실험실 문서

두 Agent가 각자 자기 팀의 일정만 알고 있을 때, 어떻게 정보를 주고받아 하나의 일정을 정할까? 이 프로젝트는 같은 문제를 여섯 소통 방식으로 풀면서 실제 대화와 결과를 관찰했다.

2026년 9월 11일에 방식별 5회, 총 30회를 실행했다. 유효한 일정에 합의한 경우는 29회, 최적 점수에 도달한 경우는 28회다.

## 처음 읽는다면

**[여섯 소통 방식 실험 보고서](experiment-insights-v3-1.md)**를 먼저 읽는다. 프로젝트를 처음 접하는 독자가 가설부터 실제 대화, 결과와 해석까지 한 문서에서 따라갈 수 있도록 구성했다.

| 읽는 순서 | 답하는 질문 |
|---|---|
| [1. 프로젝트 가설](experiment-insights-v3-1.md#hypotheses) | 자연어·JSON·논리식·벡터·바이트코드·공동 언어로 소통하는 것이 각각 효율적인가? |
| [2. 공통 문제와 각 단계별 과정](experiment-insights-v3-1.md#process) | 자기 팀의 일정만 아는 두 Agent가 공동 회의를 정하기 위해, 각 방식에서 어떻게 대화했는가? |
| [3. 실험 결과](experiment-insights-v3-1.md#results) | 성공·품질·모델 비용·시간·통신량은 어떻게 달랐는가? |
| [4. 핵심 인사이트](experiment-insights-v3-1.md#insights) | 각 방식의 효율성 질문에 어떤 답을 얻었으며, 대화와 결과에서 무엇을 배울 수 있는가? |

대화 사례는 원기록을 한국어로 풀어 쓴 요약이며 원문 링크를 함께 제공한다. 가설은 설명을 위해 정리한 작업 가설이고, 사전에 등록한 통계 검정 가설로 소개하지 않는다. 1~6단계는 소통 방식 번호이며, 후속 계획의 1~4차 연구와 다르다.
