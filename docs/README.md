## 연구 로드맵

연구 로드맵의 1~4차는 연구 범위다. 사용자 실행 요청의 1~6단계는 소통 방식이며 서로 다른 번호 체계다.

| 연구 범위 | 목적 | 실행 상태 |
|---|---|---|
| 1차 | 같은 일정 과제에서 여섯 방식의 자율 소통·성과·비용 관찰 | 구현·오프라인 검증 완료, 실제 실험 대기 |
| 2차 | 사람이 활용하는 대화·위키·히스토리의 정확성·이해 가능성과 생성 비용 관찰 | 후속 계획 |
| 3차 | 다른 작업 유형·문제군에서 방식의 특성과 적용 조건 확인 | 후속 계획 |
| 4차 | 표현·전송·정보 공유·사전 합의 요소의 효과를 분리 | 후속 계획 |

1차 기본 규모는 같은 문제 하나에서 방식별 5회다. 다섯 회를 서로 다른 문제로 바꾸지 않는다. 작은 표본과 단일 문제의 범위를 명시하며 보편적인 우열을 확정하지 않는다. 일반적인 Agent 전체를 대표하는 기준 구성이나 단일 Agent 대비 이득을 현재 확보했다고 주장하지 않는다.

## 4차 요소별 분리 실험

| 비교 | 바꾸는 요소 | 고정할 요소 |
|---|---|---|
| 표현 방식 | 자연어·JSON·기호식 | 문제·공통 의미·전송·행동 규칙 |
| 전송 형식 | JSON 직렬화·고정 벡터·바이트코드 | 메시지 내용·수와 복원 후 모델 입력 |
| 정보 공유 전략 | 원자료 전체·과제에 충분한 요약 | 문제·표현·전송·공통 행동 규칙 |
| 사전 합의 | 사전 즉시 제공·동일 사전의 제안·수락 | 문제·문법·최종 사전·표현 의미 |

전송 크기·복원 정확도는 모델 호출 없는 동일 메시지 검사로 확인할 수 있다. 전략을 지정하는 비교와 Agent가 그 전략을 자율 선택하는 관찰은 구분한다. 사전 합의는 전체 사용량에 포함하면서 부분 내역을 기록한다. 합의 비용을 빼는 계산만으로 합의를 제거했을 때의 성과를 예측하지 않는다.

후속 실험은 별도 명세와 요청이 있을 때 진행한다. 현재 1차에 자동으로 추가하거나 연구용 예산을 재도입하지 않는다.
