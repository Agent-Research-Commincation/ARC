# 실험 결과와 실제 대화

여섯 소통 방식을 각각 30회, 총 180회 실행한 기록이다. 실패·Agent 자체 종료도 포함하며, 서로 다른 A·B 세션 360개를 사용했다.

- [사람이 읽는 실험 보고서](../docs/experiment-report.md): 프로젝트 가설 → 공통 문제와 단계별 과정 → 결과 → 핵심 인사이트.
- [180회 대화 찾아보기](20260912T170838Z-plan-22772406666b/README.md): 방식별 30개 회차, 두 Agent의 실제 입력·응답·제출.
- [상세 측정표](20260912T170838Z-plan-22772406666b/analysis/metrics.md): 비용·시간·전송량·토큰·검수·후보 변경.

이 폴더는 읽기용 기록과 선택한 사후 검수를 보존한다. 원본은 `results/experiment/`, worktree 원본은 `.worktree/`에 있으며 파일 해시로 동일성을 확인했다. 대화 기록은 실제 발화와 전달·거절·제출 이벤트다. 공개되지 않은 모델 내부 생각을 재구성한 문서가 아니다.
