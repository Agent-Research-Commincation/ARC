# 3/07·3/27의 B·M1 요약 값 비교

현재 27~28회차 지표에 3/07 결과를 합치지 않았다. 비교 대상은 3/07 m2와 3/27 m4에 명시된 B·M1 요약 24개다.

두 원문의 24개 값은 모두 같으며 각 메시지의 B·M2 24개 값과도 같다. 원자료로 B 구성원 7개 부분집합을 계산했을 때 **B1+B2만 24/24개가 일치**했다. 실제 M1의 B 참석자는 B1 한 명, M2의 B 참석자는 B1·B2다.

|---:|---|---|---|---|
|0|1/4|1/4|1/2|1/4|

실제 B1 값과는 24개 중 13개가 맞고 11개가 다르다. 3/27은 m2에도 슬롯0 선호도 4를 보냈으므로 오류 발생 수는 12이고 잘못된 고유 키는 11개다. 관측 값의 일치만 확인했으며 복사·참석자 오인 등 내부 생성 원인은 판정하지 않았다.
