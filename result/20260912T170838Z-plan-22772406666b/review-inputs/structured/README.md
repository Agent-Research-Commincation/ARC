# 구조화 메시지 검토 근거

[대화·결과 안내](../../README.md) · [150회 범위 확인](structured-audit-29-30/coverage-150.md)

2~6단계의 각 30회, 총 150회를 검토했다. 전체 전달 메시지의 구조화 주장은 원자료로 자동 검산했으며 별도 AI가 산술과 선정 원문을 확인했다. 모든 메시지를 사람이 읽은 검수는 아니다. 선택한 최종 평가와 원문은 각 방식의 selected-review/에 있다. 아래는 실행 후 작성한 AI 검토 근거다.

메모의 기존 절대 경로는 검토 당시 원본 위치다. 일반 열람은 상단 대화 안내에서 회차를 여는 방법을 권한다. 검산 스크립트는 추가 실험 모델을 호출하지 않았고, AI 사후 검토 비용은 180회 실험 A·B의 모델 비용에 포함하지 않는다.
