# 2~6단계 trial23 추가 감사

5회 모두 최초 전체 후보와 최종 제출이 `(M1,M2,M3)=(1,6,10)`, 유효·20점이다. 내용은 **정답714 / 오류0 / 보류0**, 전달된 task 메시지는20개, 코덱 오류는0건이다. 별도 프로토콜 거절은10건(3단계8·6단계2)이다. 모든 단계에서 후보 변경·revise는 없었다.

## 정보 교환과 후보는 별개의 흐름

적용된 **task 메시지11개**는 다음과 같다.

|메시지|실제 전달된 내용|
|---|---|
|m1 A|자기 팀 가용 슬롯의 가용성·선호도 요약48개와 B1~B3 개인 정보 요청.|
|m2 B|B1~B3의 모든 슬롯 개인 자료72개.|
|m3 A|최적 후보 `(1,6,10)` 제안.|
|m4 B → m5 A|A·M1·슬롯0의 선호도1개 질문 → 값4 응답.|
|m6 B → m7 A|같은 회의·슬롯의 가용성1개 질문 → 값0 응답.|
|m8 B → m9 A|A·M1의 슬롯2·5·6·10, A·M2의 슬롯0·5·10에 대한 가용성·선호도14개 질문 → 해당14개 응답.|
|m10 B → m11 A|A·M3·슬롯3의 가용성·선호도2개 질문 → 값0·1 응답.|

질문 네 묶음 **1+1+14+2=18개**와 응답키가 정확히 일치한다. A 요약은 초기48개에서 서로 다른18개가 추가되어 **66개**가 전달됐다. 적용된 A 요약끼리 같은 키를 반복한 것은 없다. M3 슬롯2·6·7의 가용성·선호도6개는 끝까지 전달되지 않았다. 첫48개가 원본에서 A 팀이 가능한 회의·슬롯의 집합과 일치하지만, 생략된 값을 불가 주장으로 채워 넣지는 않았다.

**m3 이후 후보는 바뀌지 않았다.** 추가 대화8개는 요약 질문·응답이며, 마지막 request-20 B와 request-21 A가 같은 후보를 제출했다. 3/23의21개 제어 응답은 send11·submit2·거절8이고 wait·stop·revise는 없다. 길어진 대화를 후보 재협상이나 제어 정체로 표현하면 원문과 다르다. 거절된 응답의 반복과 실제 peer에게 전달된 정보의 반복도 구분해야 한다.

## 나머지 단계의 관찰

- **6/23:** 사전 정의·수락은 바로 적용됐다. A의 첫 task는 종류가 없어 `Message kind is required`로 거절됐고, `info().`만 앞에 추가해 전달했다. 이후 제안과 `asksum(score,A,M1,1).`를 함께 보낸 응답은 `Invalid question type or arguments`로 거절됐다. 다음 m5는 질문을 제거하고 같은 후보만 전달했다. 올바른 점수 질문으로 고쳐 응답받은 기록은 없다.
- **5/23:** A 제출 → B wait → A wait → B 제출 순서다. 두 wait 동안 A 제출은 유지됐고 후보 전달 이후 새로운 peer 메시지는 없다.
- **2/23·4/23:** 자료 교환, 최적 후보, 양쪽 제출로 완료됐다. 이 두 단계의 task 원문은 직접 독해 대상이 아니며 자동대조·정규화 검토로 확인했다.

전체 task 적용 제어는 send20·submit10·wait2다. setup 적용2개·task 거절10개를 합쳐 총44개 응답이다. 실패·미제출 종료는 없었다.

## 검산·직접 읽은 범위

- 같은 고정 평가기로 task20개·제어 응답44개를 자동 대조했다. 형식화된 질문90개와 개인 정보 전반 요청은 사실 주장으로 세지 않았다. 전달된 코덱 오류0과 전달 전 거절10을 분리했다.
- 직접 읽은 task 원문은 **14/20개**: 3/23 m1~11 전체, 6/23 m3~5 전체. 거절 응답10개 전체, 3/23 최종 제출2개, 5/23 제출/wait4개와 6단계 사전도 읽었다. 나머지는 자동대조·정규화 검토이며 완전 수동 전수검수는 아니다.
- 기존 평가기 산술 함수를 쓰지 않고 추출 주장714개(팀 요약570·개인 사실144), 전체 후보5개·최종5개를 원본 문제로 재계산했다. 모두 기존 판정과 일치했다. 요청·응답키, 후속 요약의 고유성 및 미전달6개, 거절 응답의 실제 수정·제거를 별도 대조했다. 주장 추출 자체는 기존 파서를 사용했다.
- 1,728개 배정 중 유효54개·유일 최적20점도 확인했다. 원본 파일과 실행 소스 해시가 전후 동일하고 단계별 평가 소스도 같다. 코어·설정·원본 수정 및 추가 모델 실행은 없었다. 방식의 우열·비용 순위 일반화는 범위 밖이다.
