# Agent 소통 방식 실험실

이 프로젝트에서 **“1단계 해줘”**라고 요청하면 자연어 방식만 5회 실행한다. 단계는 소통 방식 번호이며, 앞 단계를 먼저 실행해야 하는 순서가 아니다.

| 요청 | 소통 방식 | 직접 실행 |
|---|---|---|
| 1단계 해줘 | 자연어 | `python3 lab.py run 1` |
| 2단계 해줘 | 정해진 JSON 구조 | `python3 lab.py run 2` |
| 3단계 해줘 | 논리식·관계 그래프 | `python3 lab.py run 3` |
| 4단계 해줘 | 고정 의미 특성 벡터 | `python3 lab.py run 4` |
| 5단계 해줘 | 바이트코드 | `python3 lab.py run 5` |
| 6단계 해줘 | Agent 공동 기호 언어 | `python3 lab.py run 6` |

한 요청은 선택한 단계의 5회 본실험이다. 매회 두 Agent를 각각 새 세션으로 시작하고, 끝나면 보고서를 저장한다. 다른 단계는 자동 실행하지 않는다. 자연어 요청의 실행 규칙은 [AGENTS.md](AGENTS.md)에 있다.

## 실행 환경

- macOS 또는 Linux, Python 3.9 이상. Python 외부 패키지 설치는 필요 없다.
- 로그인된 Codex CLI. 현재 확인한 버전은 `0.153.4`이다.
- 두 Agent 모두 `gpt-5.6-luna`, 추론 수준 `high`, 기본 서비스 티어를 사용한다.
- 실제 실행에는 Codex의 로컬 상태 및 네트워크 접근이 필요하다. 제한에 걸리면 해당 명령의 권한 절차를 사용한다.
- 전역 Codex 설정과 로그인 정보를 수정하지 않는다. 실험용 설정을 실행별로 전달한다.

## 준비 상태와 점검

```bash
python3 lab.py status
python3 lab.py check
```

두 명령은 모델을 호출하지 않는다. 실제 모델 연결과 메시지 복원을 짧게 확인할 때는 다음을 사용한다. 본실험과 별도이며 모델 사용량이 발생한다.

```bash
python3 lab.py verify-live
python3 lab.py verify-live --stage 4
```

일정 과제 자체를 1회 예비 실행하려면 `python3 lab.py pilot 1`처럼 요청한다. 예비 실행은 본실험 5회에 포함하지 않는다.

단계를 지정하기 전에 Agent가 어떻게 협업하는지 관찰하려면 `python3 lab.py observe`를 사용한다. 매회 새 Luna high 두 세션에 각자의 동일 합성 일정만 제공하고 메시지 내용·형식을 자율 선택하게 하여 **5회** 실행한다. `results/observation/`에 회차별 지표와 실제 대화 원문을 저장한다. 공통 입력·행동 외피는 JSON이고 도구 제한·교대 발언·제출 규칙은 유지하므로, 여기서 기본 상태는 **실험 환경에서 소통 형식을 지정하지 않은 상태**를 뜻한다. Codex 제품의 기본 동작이나 통상적인 Agent 전체를 대표하지 않는다.

`observe`는 일정 과제를 직접 풀면서 협업을 관찰한다. `verify-live`는 미리 정한 짧은 메시지의 전송·복원을 점검한다. 두 명령 모두 가상으로 만든 데이터를 실제 모델에 보내며 사용량이 발생하고, 1~6단계 본실험 5회에는 포함하지 않는다.

**현재 검증 상태(2026-09-09):** 오프라인 테스트 55개 통과. 기본 상태 협업을 동일 조건에서 매회 새 Luna high A·B 세션으로 **5회 실행했고 전부 26점 최적해로 성공**했다. 세션 ID 10개가 모두 다름을 확인했다. 여섯 방식별 전송 검증과 단계별 본실험은 아직 미수행이다. [5회 분석과 원문](docs/basic-observation-five-runs.md).

## 기본 문제와 상한

참석자 6명을 두 Agent에 3명씩 나누어 제공한다. 회의 3개를 2일 동안 12개의 1시간 슬롯에 배치한다. 가능 시간, 참석자 중복, M1→M3 순서를 지키고 참석자의 선호 점수 합계를 최대화한다. 유효 시간표는 54개, 최적 점수는 26점이다. 이 정답은 평가기만 사용한다.

[공통 설정](config/experiment.json)과 [고정 일정 데이터](config/problem.json)에 저장되어 있다. 회차당 600초, 호출당 120초, 작업 대화 기회 24회, 메시지 20개가 기본 상한이다. 6단계 언어 합의에는 최대 6회의 별도 기회를 주며 메시지·시간·사용량은 같은 회차 총량에 포함한다. 토큰 상한 100,000은 호출 완료 후 확인하므로 마지막 호출만큼 초과할 수 있다.

## 결과와 해석

`python3 lab.py compare`로 기존 본실험을 비교한다. 결과는 `results/experiment/<실행 ID>/`의 `manifest.json`, `summary.json`, `report.md`와 회차별 `events.jsonl`, `result.json`에 저장한다. 검증·예비 실행은 별도 폴더에 저장하고 본실험 비교에서 제외한다. 재실행은 새 ID를 만들며 기존 결과를 덮어쓰지 않는다.

- 4단계는 의미 특성 158개를 256차원 직교 변환한 float32 벡터다. 학습된 임베딩이나 Luna 내부 잠재 상태를 사용하지 않는다.
- 5단계는 일정 사실·제안 메시지만 처리하는 제한된 가상머신이다. 운영체제 명령이나 범용 코드는 실행하지 않는다.
- 6단계는 고정 문법 위에서 매회 기호 사전을 제안·수락한다. 이전 회차의 사전은 재사용하지 않는다.
- 금액은 [공식 API 단가](https://developers.openai.com/api/docs/models/gpt-5.6-luna)에 기반한 추정이며 실제 구독 청구액이 아니다. 로컬 CPU 단가가 미설정이면 총비용은 미측정으로 두고 모델 비용 추정을 별도로 보고한다.
